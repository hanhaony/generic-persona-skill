## 5. **新缺陷 D-289（P1，已修）：引文核验"折空白"是假的，4/4 次拒收全是误拒**

> **状态更新（2026-10-18）**：D-289 **已修**——`_norm_ws` 改为丢弃空白，15 项测试，
> `scripts/replay_p4_8_quote_rejections.py` 用当时的真实缓存复核 4/4 全部放行。
> 本节保留**发现时**的记录（缺陷说明与影响面），修复验收见 `docs/P4_8_R47_PLAN.md` §1.1。

### 5.1 现象

本轮 29 候选 → 28 证据，拒收 1 条：

```
claim = 林黛玉任情任性、真诚单纯，想说就说、想生气就生气，不担心得罪人。
quote = 她任情任性、真诚单纯，她的一生是想说就说、想生气就生气的，她不担心也不怕得罪人。
原因  = QUOTE_NOT_IN_MATERIAL（"逐字比对，允许折空白差异"）
```

**这句话就在材料里**（sinoss PDF 摘要），只差一个空格：原文是"想生气 **空格** 就生气的"（PDF 硬换行留下的空格）。

### 5.2 根因（已定位到行）

`persona/modules/claim_validation.py`

```python
def _norm_ws(text): return " ".join(str(text or "").split())   # 连续空白 → 一个空格
```

- 材料折空白后变成 `…想生气 就生气的…`（**空格被保留**）；
- 引文本身没有空格，折后仍是 `…想生气就生气的…`；
- `normalized_text.find(normalized_needle)` ⇒ **-1** ⇒ 拒收。

**"折空白"的本意是容忍换行/缩进，实现却把换行变成了一个真空格，恰好让"换行落在句内"的中文材料全部失配。**
告警文案"允许折空白差异"与实现行为不符——这正是"静默行为比报错更危险"的又一例：报错看起来"纪律生效"，
实际是**误杀**。

### 5.3 影响面：三轮累计 4/4 次拒收全是误拒

用"空白可选"匹配（`\s*` 连接每个字符）复核三轮全部拒收候选：

| 轮次 | 拒收数 | 逐字 | 现有折空白 | 空白可选 | 结论 |
|---|---|---|---|---|---|
| R4.4 | 2 | ✗ | ✗ | **✓** | 误拒（含宝玉蘅芷清芬题匾） |
| R4.5 | 1 | ✗ | ✗ | **✓** | 误拒（同一份维基文库，对联前是空行） |
| R4.6 | 1 | ✗ | ✗ | **✓** | 误拒（黛玉任情任性，句内 PDF 空格） |

丢失比例：R4.6 **1/29 = 3.4%**，R4.4 **2/27 = 7.4%**。丢的都是长材料的句子（PDF/硬换行最典型），
且**丢的这条旁边就是"她不止一次奚落贾宝玉…出言讽刺过薛宝钗"**——正是 `caustic` 的语料。

### 5.4 建议修法（**未实施，等授权**）

1. `_norm_index_map` 折空白时**丢弃**空白字符（而不是压成一个空格），使"材料有空格 / 引文没空格"与
   "材料换行 / 引文连写"两种差异都能命中；定位仍用 index map 还原到原文下标；
2. 或加第三轮 pass：两侧都删空白后 `find`，命中后再用映射回原文区间；
3. 守住红线：**改写、删字、换序必须仍然拒收**（补测试：换一个词 / 少一个分句 / 调换顺序 ⇒ 必须拒收）；
4. 补测试：句内换行、句内多空格、PDF 断行三种形态必须命中；
5. `PROMPT_VERSION` 不必改（不涉提示词）。

### 5.5 对 R4.6 结论的影响：**不改变 `traits`=0**

## 7. 其他观察（P3，不影响判定）

1. **落盘标签不准**：`raw_responses.jsonl` 里抓取那一条的 `label` 也是 `"search"`（只有 `url` 能区分），
   对账时需要额外判断——建议按 `url` 或独立 `kind` 打标。
2. **拒收候选不落库**：只有日志一行，事后无法复盘。本轮靠原始响应才查明是误拒 ⇒ 建议把
   拒收候选（含 quote 与 material_key）落审计表，否则"拒收理由"这类判断永远查不了。
3. **抓取成功但计费 0**：Tavily EXTRACT 返回 `usage=0`，与"失败不计费"不同；只登记事实，不做解释。
4. **关系档案**：5 条 `RELATION` 证据，1 条（#17"宝玉喜欢的人填的是林黛玉"）只挂单主体、
   未参与"共同经历"研判 ⇒ 关系档案 4 条支撑、1 条 `POSSIBLE_CONTRADICTION`（说法并存不裁决），符合预期。
5. **对话**：1 轮，黛玉先发言（`least_recently_spoken`），引用 persona 2 / relation 1 / memory 0。

## 8. 结论（三句话）

1. **P0 缺陷修住了**：28 条证据主体全对、`expression_style` 各归本人、串味 0 条；
   但本轮材料太干净，**不能据此宣称"修复被真实模型验证"**（强判别样本为 0）。
2. **`traits` 0/0 不是回归**：材料集漂移（5/10 源换了）使 11 个标签组全部单源，
   D-109 单源不自证 ⇒ 两条"该进 traits 的说法"都停在 `single_events`。要看 `traits` 真的立起来，
   **必须先能固定材料集**，否则每轮都在赌搜索结果。
3. **新发现 D-289 比 `traits` 0 更值得先修**：引文核验的"折空白"实现错误让三轮 4/4 次拒收全是误杀，
   而且看起来像"纪律生效"。这类"看起来对、其实在丢数据"的缺陷，比报错危险。
